# Contracts

Solidity smart contracts for TRANSEVIL, including NFT contracts with integrated zero-knowledge verification.

## Contracts

### TransevilFinale.sol
Main NFT contract with ZK proof verification for artist finale and collector witnessing.

**Features:**
- ERC-721 NFT (tokens 1-250)
- Non-transferrable RELIC (token 1000001)
- Merkle proof verification for artist finale
- Witness proof verification for collector participation
- EIP-4906 metadata update events
- Witness count tracking

### MerkleProofVerifier.sol
Auto-generated Groth16 verifier for artist finale proofs.
Generated by: `snarkjs zkey export solidityverifier`

### WitnessProofVerifier.sol
Auto-generated Groth16 verifier for collector witness proofs.
Generated by: `snarkjs zkey export solidityverifier`

### HydraNFT.sol, HydraVerseNFT.sol
Existing Hydra visualizer NFT contracts (from hydra-visualiser/).

## Deployment

Deploy all contracts with:

```bash
cd scripts
node deploy-transevil.js
```

This deploys verifiers and main contract, saving addresses to `deployment.json`.
